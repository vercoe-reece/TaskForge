# TaskForge

## Current version: v0.1

TaskForge is a command-line productivity app built in Python that turns completing real-life tasks into an RPG-style progression system.

## Features

- ✅ Persistent task storage
- ⭐ XP rewards based on task priority
- 🔴 High / 🟠 Medium / 🟢 Low priorities
- 💾 Automatic save/load functionality
- 🔥 Daily streaks
- 📅 Due dates
- 📝 Task notes
- 📦 Categories
- 🔍 Task search
- 📊 Statistics dashboard
- ✏ Task Editing
- 🔤 Task Sorting

## Planned Features

- 🔎 Task Filtering
- 📈 Level system
- 🏆 Achievements

## Why I Built This

I'm building TaskForge as part of my journey into software development. The goal is to learn Python by creating something I genuinely want to use every day.

The project is inspired by RPG progression systems (particularly Old School RuneScape), where completing real-life tasks earns XP and unlocks long-term progression.
